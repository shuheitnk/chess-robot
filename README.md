# chess-robot

あなたとの対局だけで、日々少しずつ強くなるチェスロボット。

小型ロボットアーム **SO-101** が、重力と摩擦のある物理シミュレーション（MuJoCo）の中で、本物の駒をつかんで指します。
頭脳は最初は何も知りません（駒の価値さえ知らない）。あなたと対局するたびに、その結果だけを材料に進化戦略で学び、成長し続けます。

## 2段階の学習

| 段階 | 何を学ぶか | 材料 | 方法 |
| --- | --- | --- | --- |
| 1. 技能の事前学習 | 駒をつかむ・運ぶ・置く動作（8つのパラメータ） | ランダムに駒を並べた盤で「指定の駒を指定のマスへ」 | CMA-ES |
| 2. 戦略の生涯学習 | 盤面の評価の重み（12個の特徴量） | **あなたとの対局だけ** | 対称サンプリングの進化戦略 |

### 1. 技能の事前学習（`scripts/pretrain_skill.py`）
「つかむ高さ」「指の開き」「握る強さ」「離すときの開き」「降りる速さ」「運ぶ速さ」「待つ時間」「移動の高さ」を、
ランダムな初期値から CMA-ES で最適化します。毎世代、駒10〜28個をランダムに並べた盤で課題を解かせ、

- 置いた位置のずれ（3mm以内で成功）
- 周りの駒を動かしてしまった量
- 駒が倒れたか
- かかった時間

で評価します。成功率が目標（既定 95%）に届いたら「安定」として `~/.chess-robot/skill.json` に保存し、対局で使えるようになります。

**最初の事前学習の結果（14世代・候補8・各3課題）**：駒24個のランダム配置で12課題を解かせたテストで、
ランダムな初期値も学習後も成功率は100%（置き位置のずれは平均0.2mm）。学習で変わったのは速さで、
1回の移動が平均16.1秒 → 10.6秒になりました（指を大きめに開いて素早く降り、運ぶ時間と待ち時間を短く）。
動作の土台が丈夫なぶん、今の課題では「速くても失敗しない動き」を探す学習になっています。
置き位置のばらつきや駒の向きを大きくするなど、課題を難しくすると、成功率そのものの差が出てくるはずです。

動作そのものの土台（逆運動学、指を真下に向けたまま降りる、周りの駒から指が一番離れる向きを16方向から選ぶ、重力によるたわみの補正）は `chess_robot/robot.py` にあります。

### 2. 戦略の生涯学習（`chess_robot/brain.py`）
- 盤面の評価 ＝ 特徴量 × 重み。特徴量は「ポーン・ナイト・ビショップ・ルーク・クイーンの数の差」「動ける手の数」「中央の支配」「相手キング周りへの圧力」「ポーンの前進」「王手」「駒の展開」「ただで取られる駒」
- 重みは **すべて 0 から始まる**（＝合法手をランダムに指すのと同じ）
- 2手先まで読むアルファベータ探索で手を選ぶ
- 学習：1局目は「重み ＋ σε」、2局目は「重み − σε」で指し、報酬が良かった向きへ重みを動かす
- **報酬 ＝ ゲーム終了時に取った駒の点数 − 取られた駒の点数**（P=1, N=3, B=3, R=5, Q=9）
- 状態は `~/.chess-robot/brain.json`、全対局の記録は `~/.chess-robot/history.jsonl` に残り、日をまたいで育ち続けます

対局の前後に「Day 7 ・ これまでの対局 23 局」「いま大事だと思っていること：クイーン +1.84 …」のように、成長の様子が表示されます。

## 使い方

[uv](https://docs.astral.sh/uv/) を使います。

```bash
uv sync
uv run python scripts/setup_model.py        # SO-101 の公開モデルを取得してシーンを作る
uv run python scripts/pretrain_skill.py     # 技能の事前学習（数十分）
uv run python scripts/play.py               # 対局！（ロボット＝白、あなた＝黒）
```

- `scripts/play.py --text`：物理なしで盤面の文字表示だけ。たくさん対局して育てたいとき
- `scripts/play.py --record game.mp4`：対局の動画を保存
- `scripts/demo_video.py --out demo.mp4`：ロボットが決まった棋譜を指すデモ動画

### 育てたデータの保存場所

技能・頭脳・対局の記録は、リポジトリの外の `~/.chess-robot/`（Windows なら `C:\Users\<ユーザ名>\.chess-robot\`）に保存されます。
リポジトリを消したりクローンし直したりしても、頭脳はそのまま残ります。

| ファイル | 中身 | 消すと |
| --- | --- | --- |
| `brain.json` | 頭脳（評価の重み・対局数） | 生まれたての状態に戻る |
| `history.jsonl` | 全対局の記録（棋譜・報酬・その時の重み） | 記録だけ消える（強さは変わらない） |
| `skill.json` | 駒を動かす技能 | 事前学習をやり直す必要がある |

別の場所に置きたいときは、環境変数 `CHESS_ROBOT_DATA` にフォルダを指定します（Google Drive などの同期フォルダにすれば、別の PC でも同じ頭脳を育てられます）。
以前の版でリポジトリの中の `data/` に保存していたファイルは、初回の起動時に自動で移されます。

手の入力は `e5` `Nf6` のような棋譜表記か `e7e5` の形式。`resign`（投了）、`quit`（学習せずに中断）、`help`（合法手の一覧）。

## 見た目

- 駒：スタントン型。断面を回転させた回転体のメッシュ（ナイトは横顔を丸く押し出した形）。象牙色と黒檀色の光沢素材
- 盤：メープルとウォールナットのマス、真鍮の縁取り、つやのある枠
- アーム：白い外装と黒いサーボ。高さ3cmの台に載せ、暗い背景に3灯の照明

## シミュレーション上の工夫と割り切り

- 駒の衝突形状は「台座（半径6.5mm・高さ8mm）＋細い胴体」。アームは台座をつかむ
- 指先には摩擦の大きいパッドを付け、指の力は弱めに設定（実機ではトルク上限で設定できる）
- アームの各リンクに重力補償を入れて、位置制御のたわみを抑えている
- 公開モデルの衝突形状は凸包で実物より太いため、アームを折りたたんだときの見かけ上の自己衝突は除外している
- あなたの手は「見えない手」が駒を運ぶ（物理ではなく位置を直接動かす）
- ポーンが成っても、シミュレーション上の駒の形はポーンのまま（盤の状態は正しく成る）
- 駒が4mm以上ずれたときは、位置を直してから対局を続ける
